# NextTask
NextTask is a task randomizer and a completed tasks archive.

Example name input: Thermodynamics

Example weight input: 1
The higher the weight the more likely it will be chosen.

Example On/Off input: 1
1 for keeping task in randomizer selection and 0 for ignoring from selection

Example randomizer input: Number [1-20], letter [a-z], characters [aaa-zzzz], exercise [push ups, pull ups, squats]

Choice type selection can have their own weights inside (0 to turn off). Example: exercise [push ups/2, pull ups/4, squats/0]

Click on the labels to edit only a specific column for a selected task.

"Find weights based on chance" from Edit menu lets you give tasks your own chance to be chosen.
