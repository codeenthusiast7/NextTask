# NextTask
NextTask is a task randomizer and an archive.

Example name input: Thermodynamics

Example weight input: 1
The higher the weight the more likely it will be chosen.

Example On/Off input: 1
1 for keeping task in randomizer selection and 0 for ignoring from selection

Example randomizer input: Chapter [1-20], letter [a-z], characters [aaa-zzzz], exercise [push ups, pull ups, squats]

Click on the labels to edit only a specific column for a selected task.
